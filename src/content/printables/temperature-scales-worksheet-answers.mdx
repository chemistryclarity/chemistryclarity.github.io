## A. Understanding

<Q n={1}>The factor 9/5.</Q>
<Answer>The same temperature interval is 180 °F or 100 °C, so 1 °C is the same size as 180/100 = **9/5 = 1.8 Fahrenheit degrees**. To convert, multiply the Celsius value by 9 °F/5 °C (and allow for the different zero points with the 32 °F).</Answer>

<Q n={2}>Kelvin vs Celsius.</Q>
<Answer>Any two of: kelvin has **no degree sign** (300 K, not 300 °K); kelvin **starts at absolute zero**, so it is never negative; kelvin must be used in gas-law and other calculations involving ratios of temperatures. (The size of one kelvin and one Celsius degree is the same.)</Answer>

## B. Celsius and Fahrenheit

<Q n={3}>To °F.</Q>
<Answer>

$T_\text{F} = (9\ °\text{F}/5\ °\text{C}) \times T_\text{C} + 32\ °\text{F}$

(a) $(9\ °\text{F}/5\ °\text{C})(100\ °\text{C}) + 32\ °\text{F} = 180\ °\text{F} + 32\ °\text{F} = \textbf{212.0 °F}$

(b) $(9\ °\text{F}/5\ °\text{C})(-10\ °\text{C}) + 32\ °\text{F} = -18\ °\text{F} + 32\ °\text{F} = \textbf{14.0 °F}$

(c) $(9\ °\text{F}/5\ °\text{C})(37.5\ °\text{C}) + 32\ °\text{F} = 67.5\ °\text{F} + 32\ °\text{F} = \textbf{99.5 °F}$

</Answer>

<Q n={4}>To °C.</Q>
<Answer>

$T_\text{C} = (5\ °\text{C}/9\ °\text{F}) \times (T_\text{F} - 32\ °\text{F})$

(a) $(5\ °\text{C}/9\ °\text{F})(50\ °\text{F} - 32\ °\text{F}) = (5\ °\text{C}/9\ °\text{F})(18\ °\text{F}) = \textbf{10.0 °C}$

(b) $(5\ °\text{C}/9\ °\text{F})(0\ °\text{F} - 32\ °\text{F}) = (5\ °\text{C}/9\ °\text{F})(-32\ °\text{F}) = \textbf{−17.8 °C}$

(c) $(5\ °\text{C}/9\ °\text{F})(451\ °\text{F} - 32\ °\text{F}) = (5\ °\text{C}/9\ °\text{F})(419\ °\text{F}) = \textbf{232.8 °C}$

</Answer>

## C. Kelvin

<Q n={5}>To kelvin.</Q>
<Answer>

(a) $25\ °\text{C} + 273.15 = \textbf{298.15 K}$

(b) $-196\ °\text{C} + 273.15 = \textbf{77.15 K}$ (about 77 K)

(c) First to °C: $(5\ °\text{C}/9\ °\text{F})(212\ °\text{F} - 32\ °\text{F}) = 100\ °\text{C}$; then $100\ °\text{C} + 273.15 = \textbf{373.15 K}$

</Answer>

<Q n={6}>300 K.</Q>
<Answer>

$T_\text{C} = 300\ \text{K} - 273.15 = \textbf{26.85 °C}$ (26.8 °C to three significant figures: an exact 5 rounds to the even digit)

$T_\text{F} = (9\ °\text{F}/5\ °\text{C})(26.85\ °\text{C}) + 32\ °\text{F} = 48.33\ °\text{F} + 32\ °\text{F} = \textbf{80.3 °F}$

</Answer>

## D. Temperature changes

<Q n={7}>A rise of 15 °C.</Q>
<Answer>

A kelvin is the same size as a Celsius degree, so the rise is **15 K**. In Fahrenheit, use only the size factor (the 32 °F offsets cancel for a change):

$(1.8\ °\text{F}/°\text{C})(15\ °\text{C}) = \textbf{27 °F}$

</Answer>

## E. Where the scales meet

<Q n={8}>−40.</Q>
<Answer>

Let the same number be $x$. Then $x = \tfrac{9}{5}x + 32$, so $x - \tfrac{9}{5}x = 32$, $-\tfrac{4}{5}x = 32$ and $x = \textbf{−40}$.

Check: $(9\ °\text{F}/5\ °\text{C})(-40\ °\text{C}) + 32\ °\text{F} = -72\ °\text{F} + 32\ °\text{F} = -40\ °\text{F}$ ✓

</Answer>

<Q n={9}>Kelvin and Fahrenheit.</Q>
<Answer>

Write °F in terms of K: $T_\text{F} = \tfrac{9}{5}(T_\text{K} - 273.15) + 32$. Set $T_\text{F} = T_\text{K} = x$:

$x = \tfrac{9}{5}x - 491.67 + 32$, so $-\tfrac{4}{5}x = -459.67$ and $x = \textbf{574.59}$

So **574.59 K = 574.59 °F**, which is $574.59\ \text{K} - 273.15 = \textbf{301.44 °C}$.

Kelvin and Celsius numbers are **never** equal: $T_\text{K} = T_\text{C} + 273.15$ always differ by 273.15, because the two scales have the same size of degree but different zero points.

</Answer>
