## A. Understanding

<Q n={1}>Why balance?</Q>
<Answer>Atoms are rearranged in a reaction, never created or destroyed (**conservation of mass**), so each element must have the same number of atoms on both sides.</Answer>

<Q n={2}>Coefficient vs subscript.</Q>
<Answer>The 2 in $\ce{2H2O}$ is a **coefficient**: it means two water molecules. The 2 in $\ce{H2O}$ is a **subscript**: two H atoms in each molecule, part of what makes it water. Only coefficients may be changed; changing a subscript would change the substance (e.g. $\ce{H2O2}$ is hydrogen peroxide).</Answer>

## C. Balancing

<Q n={4}>Balance.</Q>
<Answer>(a) $\ce{N2 + 3H2 -> 2NH3}$ (b) $\ce{2Mg + O2 -> 2MgO}$ (c) $\ce{2H2O2 -> 2H2O + O2}$ (d) $\ce{2Fe + 3Cl2 -> 2FeCl3}$</Answer>

<Q n={5}>Balance.</Q>
<Answer>(a) $\ce{4Al + 3O2 -> 2Al2O3}$ (b) $\ce{2KClO3 -> 2KCl + 3O2}$ (c) $\ce{Zn + 2HCl -> ZnCl2 + H2}$</Answer>

<Q n={6}>Combustion.</Q>
<Answer>(a) $\ce{C2H4 + 3O2 -> 2CO2 + 2H2O}$ (b) $\ce{C2H5OH + 3O2 -> 2CO2 + 3H2O}$. Remember the O already in ethanol: right side 4 + 3 = 7 O, so 7 − 1 = 6 O from $\ce{O2}$. (c) $\ce{2C4H10 + 13O2 -> 8CO2 + 10H2O}$. With 1 $\ce{C4H10}$ you would need 6½ $\ce{O2}$, so double everything.</Answer>

<Q n={7}>Polyatomic ions.</Q>
<Answer>(a) $\ce{2AgNO3 + CaCl2 -> 2AgCl + Ca(NO3)2}$ (b) $\ce{H2SO4 + 2NaOH -> Na2SO4 + 2H2O}$ (c) $\ce{Al2(SO4)3 + 3Ca(OH)2 -> 2Al(OH)3 + 3CaSO4}$</Answer>

## D. From words to equations

<Q n={8}>Sodium and water.</Q>
<Answer>$\ce{2Na + 2H2O -> 2NaOH + H2}$. Check: Na 2 = 2, H 4 = 4, O 2 = 2.</Answer>

## E. Challenge

<Q n={9}>Check and balance.</Q>
<Answer>(a) **Not balanced:** H and Cl are 1 on the left but 2 on the right. Balanced: $\ce{CaCO3 + 2HCl -> CaCl2 + H2O + CO2}$ (b) $\ce{6CO2 + 6H2O -> C6H12O6 + 6O2}$. Check: C 6 = 6, H 12 = 12, O 18 = 18.</Answer>
