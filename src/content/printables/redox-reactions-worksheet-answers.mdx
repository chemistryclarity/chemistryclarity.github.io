## A. Understanding

<Q n={1}>Definitions.</Q>
<Answer>**Oxidation** is the loss of electrons; the oxidation number **increases**. **Reduction** is the gain of electrons; the oxidation number **decreases**.</Answer>

## B. Oxidation numbers

<Q n={2}>Oxidation numbers.</Q>
<Answer>(a) **−3** (b) **+5** (c) **+6** (d) **+6** (e) **+3** (f) **−1** (peroxide) (g) **+4** (h) **+5**. For example, (h): x + 3(−2) = −1, so x = +5.</Answer>

## C. Agents and half-equations

<Q n={3}>Chlorine and bromide.</Q>
<Answer>**Br⁻ is oxidized** (−1 → 0) and **Cl₂ is reduced** (0 → −1). **Oxidizing agent: Cl₂**; **reducing agent: Br⁻**.</Answer>

<Q n={4}>Half-equations.</Q>
<Answer>Oxidation: $\ce{Mg -> Mg^2+ + 2e-}$. Reduction: $\ce{2H+ + 2e- -> H2}$.</Answer>

<Q n={5}>Redox or not?</Q>
<Answer>(a) **Not redox**: no oxidation number changes. (b) **Redox** (disproportionation): O goes from −1 to −2 in H₂O and to 0 in O₂. (c) **Not redox**: a precipitation in which all oxidation numbers stay the same.</Answer>

## D. Balancing

<Q n={6}>Copper and silver.</Q>
<Answer>Cu loses 2 e⁻; each Ag⁺ gains 1 e⁻, so 2 Ag⁺ are needed: $\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$. Charge: +2 = +2. ✓</Answer>

<Q n={7}>Dichromate and iron(II).</Q>
<Answer>

Reduction: $\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}$

Oxidation (× 6): $\ce{6Fe^2+ -> 6Fe^3+ + 6e-}$

Overall: $\ce{Cr2O7^2- + 14H+ + 6Fe^2+ -> 2Cr^3+ + 7H2O + 6Fe^3+}$. Charge: −2 + 14 + 12 = +24 on the left; +6 + 18 = +24 on the right. ✓

</Answer>

<Q n={8}>Copper and nitrate.</Q>
<Answer>

Oxidation (× 3): $\ce{3Cu -> 3Cu^2+ + 6e-}$

Reduction (× 2): $\ce{2NO3- + 8H+ + 6e- -> 2NO + 4H2O}$

Overall: $\ce{3Cu + 2NO3- + 8H+ -> 3Cu^2+ + 2NO + 4H2O}$. Charge: −2 + 8 = +6 = +6. ✓

</Answer>

## E. Challenge

<Q n={9}>Permanganate.</Q>
<Answer>

(a) Reduction (× 2): $\ce{2MnO4- + 16H+ + 10e- -> 2Mn^2+ + 8H2O}$; oxidation (× 5): $\ce{5C2O4^2- -> 10CO2 + 10e-}$

Overall: $\ce{2MnO4- + 5C2O4^2- + 16H+ -> 2Mn^2+ + 10CO2 + 8H2O}$. Charge: −2 − 10 + 16 = +4 = +4. ✓

(b) $n(\ce{MnO4-}) = 0.0200\ \text{mol/L} \times 0.02000\ \text{L} = 4.00 \times 10^{-4}\ \text{mol}$

$n(\ce{Fe^2+}) = 4.00 \times 10^{-4}\ \text{mol}\ \ce{MnO4-} \times \dfrac{5\ \text{mol}\ \ce{Fe^2+}}{1\ \text{mol}\ \ce{MnO4-}} = 2.00 \times 10^{-3}\ \text{mol}$

$[\ce{Fe^2+}] = \dfrac{2.00 \times 10^{-3}\ \text{mol}}{0.02500\ \text{L}} =$ **0.0800 M**

</Answer>

<Q n={10}>Basic solution.</Q>
<Answer>

Oxidation (in acid, × 2): $\ce{2Cr(OH)3 + 2H2O -> 2CrO4^2- + 10H+ + 6e-}$

Reduction (in acid, × 3): $\ce{3ClO- + 6H+ + 6e- -> 3Cl- + 3H2O}$

Add and cancel: $\ce{2Cr(OH)3 + 3ClO- -> 2CrO4^2- + 3Cl- + 4H+ + H2O}$

Add 4 $\ce{OH-}$ to both sides ($\ce{4H+ + 4OH- -> 4H2O}$):

$\ce{2Cr(OH)3 + 3ClO- + 4OH- -> 2CrO4^2- + 3Cl- + 5H2O}$

Check: O: 6 + 3 + 4 = 13 and 8 + 5 = 13; H: 6 + 4 = 10 and 10; charge: −3 − 4 = −7 and −4 − 3 = −7. ✓

</Answer>
