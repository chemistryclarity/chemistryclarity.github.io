## A. Ionic or molecular?

<Q n={1}>Classify.</Q>
<Answer>(a) **ionic** (metal K) (b) **molecular** (non-metals only) (c) **ionic** (ammonium ion) (d) **molecular** (e) **ionic** (metal Fe)</Answer>

## B. Ionic compounds

<Q n={2}>Formulas.</Q>
<Answer>

(a) $\ce{K+}$, $\ce{O^2-}$: $2(+1) + (-2) = 0$, so $\boldsymbol{\ce{K2O}}$

(b) $\ce{Mg^2+}$, $\ce{N^3-}$: $3(+2) + 2(-3) = 0$, so $\boldsymbol{\ce{Mg3N2}}$

(c) $\ce{Zn^2+}$, $\ce{Cl-}$: $(+2) + 2(-1) = 0$, so $\boldsymbol{\ce{ZnCl2}}$

(d) $\ce{Ba^2+}$, $\ce{SO4^2-}$: $(+2) + (-2) = 0$, so $\boldsymbol{\ce{BaSO4}}$

</Answer>

<Q n={3}>Formulas with polyatomic ions.</Q>
<Answer>

(a) $\ce{Ca^2+}$, $\ce{NO3-}$: $(+2) + 2(-1) = 0$, so $\boldsymbol{\ce{Ca(NO3)2}}$

(b) $\ce{Al^3+}$, $\ce{OH-}$: $(+3) + 3(-1) = 0$, so $\boldsymbol{\ce{Al(OH)3}}$

(c) $\ce{NH4+}$, $\ce{CO3^2-}$: $2(+1) + (-2) = 0$, so $\boldsymbol{\ce{(NH4)2CO3}}$

(d) $\ce{Na+}$, $\ce{HCO3-}$: $(+1) + (-1) = 0$, so $\boldsymbol{\ce{NaHCO3}}$

</Answer>

<Q n={4}>Names.</Q>
<Answer>(a) **sodium sulfide** (b) **sodium sulfate** (c) **silver nitrate** (d) **magnesium phosphate**</Answer>

<Q n={5}>Roman numerals.</Q>
<Answer>

(a) 2 $\ce{Cl-}$ give −2, so Fe is +2: **iron(II) chloride**

(b) 3 $\ce{O^2-}$ give −6, shared by 2 Fe, so each Fe is +3: **iron(III) oxide**

(c) 1 $\ce{O^2-}$ gives −2, shared by 2 Cu, so each Cu is +1: **copper(I) oxide**

(d) 1 $\ce{SO4^2-}$ gives −2, so Cu is +2: **copper(II) sulfate**

</Answer>

## E. Challenge

<Q n={8}>Spot the errors.</Q>
<Answer>

- Copper forms $\ce{Cu+}$ and $\ce{Cu^2+}$, so the name needs a Roman numeral. In copper(II) sulfate, $(+2) + (-2) = 0$, so one sulfate is enough: **copper(II) sulfate is $\boldsymbol{\ce{CuSO4}}$**. $\ce{Cu(SO4)2}$ would need copper to be +4.
- $\ce{CaCl2}$ is ionic, so prefixes are not used, and the formula contains one calcium, not two: **calcium chloride**.

</Answer>
