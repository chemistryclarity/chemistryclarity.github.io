# Keeping Chemistry Clarity separate from your personal identity

The website never shows a personal name. These habits keep it that way.

## Before adding a PDF

Programs like Word and Google Docs save the author's name inside the PDF file.

**Word (Windows):** File → Info → Check for Issues → **Inspect Document** → tick *Document Properties and Personal Information* → **Remove All** → then export the PDF.
Also check File → Info → Properties: *Author* should be "Chemistry Clarity" or empty.

**Google Docs:** the PDF title comes from the document name, so name the document "Chemistry Clarity – [topic]". Google Docs does not add your name as the author.

**To check any PDF:** open it in a PDF reader → File → Properties. *Author* should be empty or "Chemistry Clarity".

## Before adding an image

- Images placed in `src/assets/` are re-processed when the site builds, which removes hidden photo data (camera, location).
- Images placed in `public/` are published **exactly as they are**. Only put images there that you created as graphics (diagrams, screenshots), not phone photos.
- Check that screenshots don't show your name, email, desktop, browser tabs or file paths.

## Git and GitHub

- This project is set up to record commits as **Chemistry Clarity** with GitHub's private *noreply* email address. Don't change this.
- Use the GitHub account **chemistryclarity** for everything in this repository.
- Don't mention personal accounts, institutions or names in commit messages, file names or code comments. The whole repository is public, including its history.

## Videos and social media

- Upload videos to a Chemistry Clarity-branded channel.
- Before uploading, check the video file's properties for an author name, and check screen recordings for names, notifications and open tabs.
